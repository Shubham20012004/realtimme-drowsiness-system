# Audit of main at 421995f

The two webcam programs request 30 and 60 FPS. Their producer threads publish the latest array without a sequence number. Consumers can repeatedly classify one exposure, including during calibration. Shutdown releases the capture without joining its reader. Wall-clock differences can jump. Face loss returns before clearing closure history. The next valid sample can therefore include the entire gap in the closure duration.

The basic detector uses pixel-plane EAR. The ultimate detector scales MediaPipe z by width, which is a relative coordinate, and computes a different 3-D ratio. Its 90-observation PERCLOS has a variable duration. Its 150-frame calibration accepts unstable tracks. Its mouth distances do not consistently span the lip opening. Pose failure returns three zeros indistinguishable from a valid estimate. The fatigue score is logged but does not drive the serial alert. Both detectors use code 2 on face loss. The original serial protocol is ASCII 0/1/2 and exit 3 at 9600 baud. No firmware, pin map, or ACK protocol is present. Searching arbitrary serial ports risks selecting an unrelated device.

The SQLite logger uses an unbounded queue, second-resolution session names, and invalid SQL in the final partial batch. Its no-face path skips logging. Missing confidence becomes zero. The single-table schema is visible in the writer. The 8,122,368-byte database was inventoried by Git blob identity. Direct row inspection was unavailable in this environment. Preserve the original database and all logs at this commit.
